# PaintTool SAI 2 — русская сборка

Русификация сборки Preview.2024.11.23 для 32- и 64-разрядной Windows.

[Скачать архив с обеими версиями](PaintTool-SAI2-RU-2024.11.23.zip?raw=true).
Распакуйте архив целиком и запустите `sai2.exe` из папки нужной разрядности.

Переведены меню, настройки, инструменты, параметры кистей и подсказки.
Исходные файлы программы сохранены отдельно в `Easy Paint Tool SAI 2`.

**Статус: сборка для проверки.** Статические проверки пройдены; запуск и
отображение русских надписей в Windows ещё не проверены. Имена ранее сохранённых
пользовательских кистей автоматически не меняются.
