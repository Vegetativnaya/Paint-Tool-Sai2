# Русская версия PaintTool SAI 2

Рабочие файлы находятся в `RU_paintToolSai2`. Папка `Tabletka` сохранена.

## Офлайн-лицензии на перевод

Добавлен инструмент для сборки защищённых копий с лицензией на одну установку
Windows. Исходные EXE не перезаписаны: защищённая папка создаётся отдельно после
того, как владелец создаст свой закрытый ключ. Для выдачи лицензии потребуется
код устройства получателя. Интернет при активации и использовании не нужен.

[Настройка, выдача лицензий и ограничения](RU_paintToolSai2/licensing/README.md).
После установки Python и зависимости можно открыть `RU_paintToolSai2/licensing/Owner.cmd` —
он запускает русское меню управления лицензиями.

Старые сборки и история GitHub не блокируются задним числом. Локальная защита
ограничивает обычное копирование, но не гарантирует защиту от модификации EXE/DLL.

[Проверки](RU_paintToolSai2/licensing/VALIDATION.md).
