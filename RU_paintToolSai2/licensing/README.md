# Офлайн-лицензии на русский перевод

Защита рассчитана на обычное копирование папки на другой компьютер. Запуск самой
защищённой EXE проходит через проверку подписи лицензии и кода установки Windows;
отдельный ярлык не нужен. Отсутствие DLL, лицензии или неверная подпись не
разрешают запуск. Лицензия бессрочная, без интернета и удалённого отзыва.

## Один раз на компьютере владельца

Установите Python 3.9+ с официального сайта (в Windows можно использовать `py -3`).
Откройте терминал в корне репозитория:

```powershell
py -3 -m pip install -r RU_paintToolSai2/licensing/requirements.txt
py -3 RU_paintToolSai2/licensing/owner.py init
py -3 RU_paintToolSai2/licensing/owner.py build
```

`init` попросит придумать пароль не короче 12 символов. Закрытый ключ хранится
зашифрованным в `RU_paintToolSai2/licensing/.owner/private-key.pem`.
Сохраните резервную копию всей `.owner` отдельно. Без ключа и пароля нельзя
выдавать новые лицензии для уже разданной сборки. Не создавайте новый ключ для
каждого человека. Ключ создаётся локально у владельца, а не в ChatGPT/GitHub.

`build` создаёт `RU_paintToolSai2/licensed-distribution`. Выдавайте получателям
**только эту новую папку** или её ZIP-архив. В ней обе разрядности и неизменённая
папка `Tabletka`. Компилятор получателю и владельцу не нужен: готовые шаблоны DLL
включены. Исходные рабочие EXE в репозитории не перезаписываются.

Если папка результата уже существует, сборщик остановится. Для новой сборки
задайте `build --output RU_paintToolSai2/licensed-distribution-v2`; такие другие
папки также держите локально и не публикуйте индивидуальные лицензии.

После установки зависимости можно дважды щёлкнуть `licensing/Owner.cmd`.
Появится русское меню: создание ключа, сборка, выдача и проверка лицензий.
Получателям этот файл не передаётся.

## Выдать лицензию человеку

Попросите получателя запустить новую защищённую EXE и прислать код из окна
активации или из `request-license.txt` (64 шестнадцатеричных символа).

```powershell
py -3 RU_paintToolSai2/licensing/owner.py issue --device КОД_УСТРОЙСТВА --name "Имя получателя"
```

Введите пароль ключа. Команда покажет путь к новому `translation.lic` в `licensing/issued`.
Отправьте человеку **только файл `translation.lic`**. Его нужно положить рядом
с `sai2.exe` и `SAI2RuLicense.dll`. Один файл подходит обеим разрядностям на той же
установке Windows. Имя получателя вносится в подписанную лицензию и позволяет
определить, кому она выдавалась; это не скрытая телеметрия.

Проверить файл и увидеть получателя:

```powershell
py -3 RU_paintToolSai2/licensing/owner.py inspect путь/translation.lic
```

В терминале Linux вместо `py -3` используйте `python3`.

## Что защищено и какие есть пределы

- Проверка встроена в точку входа копии EXE, выполняется до запуска SAI.
- RSA-2048 / SHA-256 проверяется штатным Windows CryptoAPI. В сборке только
  открытый ключ; закрытый ключ остаётся у владельца, зашифрованный паролем.
- Привязка — SHA-256 нормализованного `MachineGuid` установки Windows. Замена
  обычных комплектующих не меняет код; переустановка Windows обычно меняет.
- Лицензию нельзя просто отредактировать: подпись перестанет совпадать.
- Нельзя запретить физическое копирование файлов. Опытный человек может
  модифицировать EXE или DLL и обойти локальную проверку. Это ограничение
  офлайн-защиты. Клоны одной установки Windows тоже могут иметь одинаковый код.
- Старые открытые сборки и история GitHub остаются доступными. Новая защита
  не блокирует их задним числом. Публичная раздача прежних EXE позволяет
  пользоваться прежним переводом независимо от новых лицензий.
- Сохранённые рисунки и кисти не шифруются и не меняются. Компонент ничего не
  отправляет в сеть. Само лицензирование SAI и содержимое `Tabletka` не изменяются.
- `translation.lic` содержит имя получателя. Не публикуйте индивидуальные
  лицензии или запросы на GitHub. `.gitignore` исключает обычные пути секретов,
  запросов и результата сборки; не используйте `git add -f` для этих файлов.

## Разработчику

Поддерживаются только два исходных русских EXE с указанными в `pe_guard.py`
SHA-256. Другие или повторно защищённые файлы отклоняются до записи результата.
Новый код добавляется в конец PE; исходные секции и рабочая копия не изменяются.
Bootstrap сохраняет регистры и, для x64, XMM0–XMM5 и Windows ABI shadow space.
Нет упаковщика, внедрения в чужие процессы, служб или автозапуска.

Сборка DLL: MinGW-w64, `python compile_native.py`. Python-утилита лицензирования
требует пакет `cryptography`; получателям Python не требуется.

Тесты: `python -m unittest discover -s tests -v` из этой папки. Статус нативных
интеграционных проверок приведён в `VALIDATION.md`. Перед реальной раздачей
проверьте новую защищённую сборку на Windows с действующей и чужой лицензией.
