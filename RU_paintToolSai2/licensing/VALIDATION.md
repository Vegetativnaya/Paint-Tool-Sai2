# Проверка офлайн-лицензирования

Дата: 17 октября 2026 года.

## Выполнено

Все 9 автоматических тестов прошли, без пропусков:

- Создание и проверка подписанной персональной лицензии, уникальные номера.
- Отклонение подмены кода устройства, получателя, номера и подписи.
- Отклонение чужого ключа и неверной длины файла.
- Проверка формата кода устройства и имени.
- Шифрование закрытого ключа паролем, отказ при неверном пароле, запрет перезаписи ключа.
- Сборка двух разрядностей, проверка неизменности исходных файлов и `Tabletka`.
- Отказ при изменённой или повторно защищённой EXE.
- Эмуляция инструкций x86 и x64: действующая лицензия передаёт управление
  исходной точке входа, отказ/отсутствие DLL/экспорта завершают процесс.
  Проверены сохранность регистров, стека, флагов, XMM0–XMM5 и выравнивание Windows x64 ABI.
- Нативная DLL x64 под Wine: проверка RSA-подписи средствами Windows CryptoAPI,
  привязка к MachineGuid, отказ при чужой установке, повреждённой лицензии,
  другом подписанте и отсутствии лицензии. Защищённая тестовая EXE действительно
  запускает основную функцию только с действующей лицензией; отсутствие DLL
  также блокирует запуск.

Среда: Python 3.12, cryptography 50.0.0, Unicorn 2.1.4, MinGW-w64 GCC 14,
Wine 10 (x64). Обе DLL пересобраны из включённых исходников; SHA-256 — в
`bin/manifest.json`. Временные тестовые ключи не используются в готовых шаблонах.

Исходные EXE, ресурсы и `Tabletka` в репозитории не изменены. Утилита создаёт
защищённые копии в другой папке. В шаблонах DLL нет закрытого или общего
действующего ключа: открытый ключ конкретного владельца подставляется при сборке.

## Не подтверждено в этой среде

Полный запуск SAI с новой защитой в настоящей Windows, окна активации и
взаимодействие с антивирусом. Нативный запуск 32-битной DLL также не проверен:
для x86 выполнены компиляция, проверка экспортов и эмуляция кода запуска.

Перед раздачей запустите обе нужные вам версии в Windows: без лицензии,
с действующей лицензией, с лицензией другого компьютера и без DLL. Затем
проверьте открытие, рисование и сохранение обычного документа.

## Повторить проверки

Из папки `RU_paintToolSai2/licensing`:

```sh
python -m pip install -r requirements-test.txt
python -m unittest discover -s tests -v
```

Для нативного теста дополнительно скомпилируйте `tests/probe.c` (x64) и
`tests/host.c` (x64, без ASLR и COFF-символов), подготовьте Wine с поддержкой
CryptoAPI и задайте `SAIRU_WINE`, `SAIRU_PROBE64`, `SAIRU_HOST64` путями к
соответствующим исполняемым файлам. Тест работает с временным ключом и не
требует и не читает закрытый ключ владельца.
